# 개념별 설명

개념을 각자의 언어로 설명하는 공간입니다.

## 개념 지도

본인의 개념 지도를 만들면 이 목록에 `- [<아이디>](concept-map.<아이디>.md)`를 추가합니다.

- [공식 지도](concept-map.md)

## 빠른 시작

1. `concept-map.id.md`를 복사해서 `concept-map.<아이디>.md`를 만들고 개념 지도 목록에 링크를 추가합니다.
2. `<태그>.<아이디>.md`로 해당하는 개념을 설명하는 글을 작성합니다.
3. 본인의 개념 지도에서 해당 태그 줄의 개념 칸에 링크를 추가합니다.

## 파일명

- **개념**은 설명하려는 선형대수 개념입니다. (예: 내적)
- **태그**는 개념을 가리키는 영어 이름입니다. (예: `inner-product`)
  - 공식 태그는 [공식 개념 지도](concept-map.md)에 있습니다.

```text
concept/
├── concept-map.md                       공식 개념 지도
├── concept-map.id.md                    개념 지도 양식
├── inner-product.md                     내적 설명
├── inner-product.dnlfis42.md            dnlfis42의 내적 설명
├── inner-product.dnlfis42.fruitland.md  dnlfis42의 내적 설명, 비유 대상을 밝힘
└── inner-product.zelda.md               zelda의 내적 설명
```

- `<태그>.md`: 공식 개념 설명 파일
- `<태그>.<아이디>.md`: 각자가 만든 개념 설명 파일
  - 아이디는 겹치지 않도록 GitHub 아이디를 씁니다.
- `<태그>.<아이디>.<비유>.md`: 비유 대상을 명시한 개념 설명 파일

## 안내 사항

- 다른 사람의 파일은 마음대로 고치지 않습니다.
  - 의견은 PR 리뷰나 이슈로 남깁니다.
  - 의견 반영에 대한 선택은 작성한 사람이 합니다.
- 같은 비유라도 생각이 다르면 별도의 파일로 작성합니다.
